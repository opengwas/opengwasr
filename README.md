# opengwasr

[![R-CMD-check](https://github.com/opengwas/opengwasr/actions/workflows/R-CMD-check.yaml/badge.svg?branch=main)](https://github.com/opengwas/opengwasr/actions/workflows/R-CMD-check.yaml)

The R client for OpenGWAS data. It queries Analyses, Associations, top hits and LD either through the OpenGWAS API or from Store Releases downloaded to your own machine, and replaces [ieugwasr](https://github.com/MRCIEU/ieugwasr) and [gwasvcf](https://github.com/MRCIEU/gwasvcf) as the data-access layer for [TwoSampleMR](https://github.com/MRCIEU/TwoSampleMR).

> **Status: design.** Nothing is implemented yet; the package is an empty skeleton with CI. The vocabulary is in [GLOSSARY.md](GLOSSARY.md) and the decisions so far are in [docs/adr/](docs/adr/).
