# Package index

## Getting started

Find Analyses, then read their Associations.

- [`og_analyses()`](https://opengwas.github.io/opengwasr/reference/og_analyses.md)
  : Find Analyses
- [`og_tophits()`](https://opengwas.github.io/opengwasr/reference/og_tophits.md)
  : Top hits of Analyses
- [`og_associations()`](https://opengwas.github.io/opengwasr/reference/og_associations.md)
  : Associations of variants in Analyses
- [`og_phewas()`](https://opengwas.github.io/opengwasr/reference/og_phewas.md)
  : PheWAS: variants across Analyses
- [`og_range()`](https://opengwas.github.io/opengwasr/reference/og_range.md)
  : Associations in a genomic range
- [`og_variants_rsid()`](https://opengwas.github.io/opengwasr/reference/og_variants_rsid.md)
  [`og_variants_chrpos()`](https://opengwas.github.io/opengwasr/reference/og_variants_rsid.md)
  : Look up variants by rsID or position
- [`og_provenance()`](https://opengwas.github.io/opengwasr/reference/og_provenance.md)
  : Provenance of a query's result

## Large queries and Jobs

Run many queries at once, or collect them yourself.

- [`og_submit()`](https://opengwas.github.io/opengwasr/reference/og_submit.md)
  [`og_job_status()`](https://opengwas.github.io/opengwasr/reference/og_submit.md)
  [`og_job_result()`](https://opengwas.github.io/opengwasr/reference/og_submit.md)
  [`og_job_cancel()`](https://opengwas.github.io/opengwasr/reference/og_submit.md)
  : Run queries as Jobs without waiting
